# BestNoFences

An improved fork of [NoFences](https://github.com/Twometer/NoFences)  and [BetterFences](https://github.com/Damianttje/BetterNoFences)- organize your desktop with transparent containers.


On the basis of betterfences, I have added new functions. When the screen resolution changes, such as switching monitors, connecting external projectors, or being managed by remote desktops, the sizes of fences will become disordered. After detecting the resolution change, BestNoFences will calculate the appropriate window size suitable for the screen resolution according to the number of fences and then redraw the windows.

<img width="188" height="154" alt="image" src="https://github.com/user-attachments/assets/b0e00d4d-b1a0-4f15-ae30-671c2d2d40f7" />

In addition to automatic switching, an "Auto Size" menu has been added to the right - click pop - up menu of the taskbar icon, which can actively adjust the positions and sizes of all fences.
